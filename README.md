# Fut Legends

Web football game inspired by Haxball featuring legendary players like Messi, Cristiano, Maradona, Pele, Yashin, and more.

## Features

- **Haxball-style gameplay** - Top-down 2D physics-based football
- **Legend cards** - FC-style player cards with gold/icon theme
- **12+ legendary players** - Each with unique stats (PAC, SHO, PAS, DRI, DEF, PHY)
- **3v3 matches** - Pick your team of 3 legends
- **Mobile support** - Touch joystick and buttons for mobile play
- **3 difficulty levels** - Easy, Normal, Hard

## Tech Stack

- **Phaser.js** - Game engine
- **TypeScript** - Type-safe code
- **Vite** - Build tool
- **Vercel** - Deployment

## Getting Started

```bash
npm install
npm run dev
```

## Controls

### Desktop
- **Arrow keys** - Move player
- **Space** - Kick ball
- **Shift** - Sprint

### Mobile
- **Left joystick** - Move player
- **KICK button** - Kick ball
- **SPRINT button** - Sprint

## Build & Deploy

```bash
npm run build
```

Deploy to Vercel:
```bash
vercel --prod
```
